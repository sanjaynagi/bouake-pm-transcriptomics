# Selection Atlas — Signals table

## The file

`h12-signal-detection-all.csv` — one row per H12 selection signal, in one cohort, on one contig. Generated by the peak-finding notebook `workflow/gwss/notebooks/h12-signal-detection.ipynb`. Overlapping signals within a cohort are already deduplicated (highest ΔAIC wins).

## Loading

```python
import pandas as pd

signals = pd.read_csv("h12-signal-detection-all.csv")
signals.shape        # (n_signals, 30)
signals.columns
```

No dtypes need coercing — positions are integers in bp, genetic positions and peak parameters are floats.

---

## Column schema

### Identity

| Column       | Type | Description |
|---|---|---|
| `cohort_id`  | str | Cohort identifier. Format `{country}-{admin1}_{admin2}_{taxon}_{year}[_Q{quarter}]` — e.g. `BF-09_Houet_colu_2012_Q3`. Also matches `cohort_admin2_quarter` / `cohort_admin2_year` in `malariagen_data` sample metadata. |
| `contig`     | str | Compound chromosome arm, one of `2RL`, `3RL`, `X` (*Ag3*) or the *An. funestus* equivalents. |

### Peak location — fitted center

These are the centre of the fitted exponential-decay peak.

| Column    | Units | Description |
|---|---|---|
| `gcenter` | cM    | Fitted genetic position of the peak (on the genetic map for this contig). |
| `pcenter` | bp    | Physical position of the peak — `gcenter` mapped back through the recombination map. **Best single "where is the signal" coordinate.** |

### Peak location — observed maximum

The H12 value and position of the largest observed H12 window *within the span2 interval* (see below).

| Column     | Units | Description |
|---|---|---|
| `stat_max` | H12   | Maximum observed H12 across windows inside `span2`. Range 0–1. Proxy for **sweep strength / completeness**. |
| `gpos_max` | cM    | Genetic position at `stat_max`. |
| `ppos_max` | bp    | Physical position at `stat_max`. |

`pcenter` ≠ `ppos_max` in general — the model center and the observed argmax can disagree, especially for skewed or noisy signals. For plotting a point estimate prefer `pcenter`; for "what window had the biggest H12" use `ppos_max`.

### Signal intervals

Three concentric intervals around the fitted centre, derived from the fitted decay and skew. Each is reported in **both** genetic (`g*`, cM) and physical (`p*`, bp) coordinates.

| Interval | Genetic columns | Physical columns | Width | Interpretation |
|---|---|---|---|---|
| focus | `focus_gstart`, `focus_gstop` | `focus_pstart`, `focus_pstop` | center ± 0.25·decay | tight core — most likely to contain the selected locus |
| span1 | `span1_gstart`, `span1_gstop` | `span1_pstart`, `span1_pstop` | center ± 1·decay | conservative signal extent |
| span2 | `span2_gstart`, `span2_gstop` | `span2_pstart`, `span2_pstop` | center ± 2·decay | broad footprint — useful for gene overlap / LD |

Intervals use `decay_left` on the left flank and `decay_right` on the right flank (see skew below).

### Fitted peak-model parameters

Parameters of the skewed exponential-decay model fit to the H12 trace (in genetic coordinates).

| Column       | Description |
|---|---|
| `amplitude`  | Height of the peak above baseline (H12 units). Bounded [0.03, 1.5] during fitting. |
| `decay`      | Symmetric decay constant (cM). Larger = broader signal. |
| `skew`       | Asymmetry parameter in [−0.5, +0.5]. Positive ⇒ peak decays faster on the **right** (`decay_right = 2^(−skew) · decay`); negative ⇒ faster on the **left** (`decay_left = 2^(+skew) · decay`). Exactly 0 = symmetric. |
| `decay_left` | Left-flank decay constant (cM), derived from `decay` and `skew`. |
| `decay_right`| Right-flank decay constant (cM), derived from `decay` and `skew`. |
| `baseline`   | Fitted baseline H12 outside the peak. Tracks local background diversity. |

### Model-fit statistics

Used to judge signal confidence and to compare the peak fit against a null (constant) fit.

| Column        | Description |
|---|---|
| `delta_i`     | **ΔAIC = AIC(null constant model) − AIC(peak model)**, rounded to int. **Primary signal-strength / confidence score.** Larger = more support for a peak over flat. Detection threshold is `delta_i > 1000`. |
| `aic`         | Akaike Information Criterion of the peak fit. |
| `bic`         | Bayesian Information Criterion of the peak fit. |
| `rss`         | Residual sum of squares (peak fit; returned by `lmfit` as `chisqr`). |
| `constant_aic`| AIC of the null constant-model fit — used to compute `delta_i`. |

---

## Which column should I sort / filter on?

| Goal | Column |
|---|---|
| Rank by **signal confidence** | `delta_i` (descending) |
| Rank by **sweep intensity / completeness** | `stat_max` (descending; approaches 1 for a near-complete sweep) |
| Rank by **sweep breadth** | `decay` or `span2_pstop − span2_pstart` |
| Locate signal on the genome | `contig` + `pcenter` |
| Gene overlap (conservative) | `contig`, `span1_pstart`, `span1_pstop` |
| Gene overlap (broad) | `contig`, `span2_pstart`, `span2_pstop` |

## Coverage

The table currently contains **~350 signals** across **~55 cohorts**, covering *An. gambiae*, *An. coluzzii*, *An. arabiensis* and *An. bissau* from sampling sites across sub-Saharan Africa (Burkina Faso, Benin, Cameroon, CAR, Côte d'Ivoire, DRC, Ghana, Guinea, Guinea-Bissau, Gambia, Mali, Malawi, Tanzania, Uganda, etc.), with the *An. funestus* atlas covered in an equivalent table. Use `signals["cohort_id"].unique()` / `signals["contig"].unique()` to check the exact set.
